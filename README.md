## OpenAPI HttpFoundation Testing - another Laravel Example

This is an example repository to demonstrate how we use [openapi-httpfoundation-testing](https://github.com/osteel/openapi-httpfoundation-testing0 at Steadfast Collective.

## Compatibility
This example uses:
 - Laravel 12
 - PHP 8.4
 - Redocly

## Decisions & Examples
We keep our OpenAPI Specification file in Resources and build them as part of our build process.
